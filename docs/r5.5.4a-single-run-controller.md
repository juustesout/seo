# R5.5.4a - Single Designer run controller (behavior-preserving)

Status: **delivered**. One shared run controller now owns the durable Designer
run lifecycle for both surfaces, with no behavior change on either. This is the
first half of R5.5.4; the bookmark/reconnect policy change is deferred to
R5.5.4b (see the approved decisions in
`docs/r5.5.4.0-run-client-recon.md`).

## What changed

New shared pieces:

- `apps/web/src/workspace/designerRunClient.ts` - pure helpers: run paths
  (`designerRunsPath`, `designerRunPath`), the project bookmark key, the active
  status predicate (`isActiveAgentRunStatus`, derived from the contracts
  terminal predicate), and storage-safe bookmark read/write/clear.
- `apps/web/src/workspace/useDesignerRunController.ts` - the single lifecycle:
  restore from a bookmark, submit, one epoch guard, one interval poll that stops
  at terminal, a poll-attempt budget, not-found/auth stop rules, and bookmark
  read/write/clear. Policy is injected through `onRun` / `onError` / `onGone` /
  `onExhausted` / `onReset`.

Adapters (same public APIs, so call sites are unchanged):

- `apps/web/src/components/designer/useDesignerRun.ts` keeps the
  Designer-specific intent body (creation `base_revision` vs edit
  `content_id`), the project-scoped bookmark, and the view's transport copy.
- `apps/web/src/components/content/workspace/useEmbeddedAgent.ts` keeps the
  editor's submission gating, image/operations application and product state
  machine, but no longer owns epoch/poll/bookmark logic. Its two error paths are
  unified through the new pure `embeddedAgentStateFromOutcome`.

## Behavior-preserving decisions

- **Bookmark:** Designer keeps `seo.designer.run.<projectId>`; the editor still
  has none (`bookmarkKey: null`).
- **Idempotency:** no `idempotency_key` is sent; the server's reuse path remains
  unused, as before.
- **Polling:** the controller uses the Designer's interval loop for both
  surfaces; the editor's 60-attempt budget and timeout copy are preserved via
  `maxPolls` + `onExhausted`.
- **Outcome mapping:** stays with each surface. The controller returns typed
  run/error facts; `embeddedAgent.ts` still owns the editor's product vocabulary,
  and the Designer view still reads the raw run.
- **Editor reconnect:** none; the run stays session-only.
